# Evan's Guide

A personal TV guide: today's and tomorrow's listings, New York teams, new and upcoming films and series, and Film DNA pages.

Data: TV listings from TVmaze (CC BY-SA 4.0), team schedules from ESPN's public feed, film and series data from TMDB (this product uses the TMDB API but is not endorsed or certified by TMDB), streaming availability by JustWatch.

The TMDB key is not stored in this repository. Each device is set up once with a private setup link.
